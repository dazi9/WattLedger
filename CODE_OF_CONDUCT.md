# Code of conduct

WattLedger is a small technical project. Be respectful, assume good intent, and keep discussions focused on the software.

We follow the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Unacceptable behaviour includes harassment, personal attacks, and publishing private information.

Report concerns to the maintainers through a private channel (for example, a GitHub security advisory or the contact address in the repository profile). Maintainers may remove comments, close issues, or block accounts that violate these expectations.
